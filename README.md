## 1. نظرة عامة على المنظومة والهندسة المعمارية

تم تصميم منظومة **OMS (One Media Solution)** بنظام فصل مؤسسي دقيق (Separation of Concerns) مع الحفاظ على قاعدة بيانات مركزية موحدة:

```
                                  ┌───────────────────────────────┐
                                  │   OMS Business Suite (.EXE)   │
                                  │   (Electron Native Desktop)   │
                                  └──────────────┬────────────────┘
                                                 │
            ┌────────────────────────────────────┼────────────────────────────────────┐
            ▼                                    ▼                                    ▼
┌────────────────────────┐           ┌────────────────────────┐           ┌────────────────────────┐
│  📄 نظام الفواتير      │           │  📺 قسم الميديا         │           │  🛡️ الإدارة المركزية   │
│  OMS Invoice           │           │  OMS Media             │           │  OMS Central Admin     │
│  UI: 5173 | API: 5001  │           │  UI: 5174 | API: 5002  │           │  UI: 5175 | API: 5003  │
└───────────┬────────────┘           └───────────┬────────────┘           └───────────┬────────────┘
            │                                    │                                    │
            └────────────────────────────────────┼────────────────────────────────────┘
                                                 ▼
                             ┌───────────────────────────────────────┐
                             │    PostgreSQL Central Database        │
                             │    Database: `oms_invoice_db`         │
                             │    Port: 5432                         │
                             └───────────────────────────────────────┘
```

| المكون / النظام | الوظيفة والمسؤولية | منفذ الواجهة (Frontend) | منفذ الخادم (Backend API) |
| :--- | :--- | :--- | :--- |
| **🛡️ بوابة الإدارة المركزية (`admin/`)** | إدارة المستخدمين، تعيين صلاحيات الوصول (`MEDIA` / `INVOICE` / `ALL`)، تفعيل وإلغاء تنشيط الحسابات، إعادة تعيين كلمات المرور، والإحصائيات الشاملة. | `5175` | `5003` |
| **📺 بوابة قسم الميديا (`media/`)** | تخطيط وإدارة الحملات الإعلانية، حساب تكاليف القنوات والموردين، الفروق وهوامش الربح (`Net to Client` vs `Net to Channel`)، وتصدير التقارير. | `5174` | `5002` |

## 2. تطبيق الديسكتوب المتكامل (OMS Desktop Suite & .EXE)

تم بناء تطبيق الديسكتوب باستخدام **Electron** ليوفر تجربة سطح مكتب أصلية سريعة ومستقلة:

### أ) مميزات نسخة الديسكتوب:
1. **ملفات EXE جاهزة للتشغيل الفوري**:
   * **`OMS Business Suite.exe`** (في المجلد الرئيسي مباشرة): نسخة محمولة **Portable** تعمل بنقرة واحدة بدون أي تثبيت.
   * **`OMS Business Suite Setup 1.0.0.exe`** (في `desktop/release/`): برنامج تثبيت رسمي ينشئ اختصاراً على سطح المكتب وقائمة Start.
2. **أيقونة رسمية بشعار الشركة (`icon.ico`)**:
   * تم توليد أيقونة Windows مخصصة متعددة الأبعاد (16x16 حتى 256x256) من شعار **One Media Solution** الرسمي.
3. **شاشة البداية واختيار المنصات (Welcome & Portal Selection)**:
   * تفتح شاشة ترحيبية أنيقة تعرض شعار OMS في المنتصف مع 3 بطاقات تفاعلية للأقسام.
   * مؤشرات اتصال لحظية (🟢 متصل / 🔴 غير متصل) تتحدث تلقائياً كل 4 ثوانٍ.
4. **شريط عنوان مخصص (Custom Title Bar)**:
   * الشعار الرسمي موجود دائماً في الهيدر العلوي طوال جلسة العمل.
   * زر سريع **`🏠 اختيار المنصة`** للتبديل بين الأقسام دون إغلاق البرنامج.
   * أزرار تصغير، تكبير/استعادة، وإغلاق متناسقة مع هوية النظام.
   * أزرار تكبير وتصغير الشاشة (`Zoom +/-`)، إعادة التحميل (`Reload`)، وزر طباعة الفواتير مباشرة (`Print`).
5. **منسق الخوادم التلقائي (Automatic Backend Orchestrator)**:
   * عند تشغيل ملف الـ `.exe`، يقوم كود `desktop/main.cjs` تلقائياً بفحص وتشغيل:
     - خدمة **PostgreSQL** (`postgresql-x64-18`).
     - خادم **Invoice API** على المنفذ `5001`.
     - خادم **Media API** على المنفذ `5002`.
     - خادم **Admin API** على المنفذ `5003`.
   * وعند إغلاق التطبيق، يتم إنهاء كافة العمليات الخلفية بنظافة لمنع استنزاف موارد الجهاز.
6. **خادم SPA محلي مدمج (Built-in Static Server)**:
   * يخدم ملفات الـ `dist` المترجمة للواجهات تلقائياً دون الحاجة لتشغيل أوامر `npm run dev` للواجهات يدوياً.

## 3. الواجهات الخلفية وخوادم الـ API بالكامل

### 1) خادم الفواتير والمحاسبة (`Invoice/server/` - المنفذ `5001`)
* **بيئة التشغيل**: Node.js مع Express.js و TypeScript.
* **إدارة البيانات**: Prisma ORM (v5) المتصل بقاعدة بيانات PostgreSQL المركزية.
* **أبرز المسارات والـ Endpoints**:
  * `POST /api/auth/login`: تسجيل الدخول، التحقق من التشفير بـ bcryptjs، وإصدار JWT Token.
  * `GET /api/auth/me`: جلب بيانات المستخدم المصرح له.
  * `GET /api/invoices`: جلب الفواتير مع التصفية والترتيب والترقيم (Pagination).
  * `POST /api/invoices`: إنشاء فاتورة جديدة مع احتساب بنود الخدمات والضرائب (VAT 14% و WHT 1%).
  * `GET /api/invoices/:id`: تفاصيل الفاتورة وحالات الاعتماد وسجل المدفوعات.
  * `PATCH /api/invoices/:id/status`: تحديث حالة الفاتورة (DRAFT, PENDING, APPROVED, ISSUED, PAID).
  * `POST /api/approvals/:invoiceId/action`: اعتماد أو رفض الفاتورة من قبل المدير المالي.
  * `POST /api/payments`: تسجيل دفعة مالية (تحويل بنكي، كاش، شيك، دفع إلكتروني).
  * `GET /api/clients`: إدارة العملاء وتفاصيلهم الضريبية.
  * `GET /api/services`: دليل الخدمات وأسعارها الرسمية.
  * `GET /api/reports/summary`: ملخص مالي شامل للإيرادات والمبالغ المحصلة والمتبقية.
  * `GET /api/audit-logs`: سجل تدقيق لكافة العمليات الحساسة في النظام.

### 2) خادم قسم الميديا (`media/backend/` - المنفذ `5002`)
* **بيئة التشغيل**: Node.js مع Express.js و TypeScript.
* **إدارة البيانات**: Prisma ORM مع Prisma Raw Queries لحسابات التحليل المالي السريعة.
* **أبرز المسارات والـ Endpoints**:
  * `POST /api/auth/login`: تسجيل دخول موظفي ومديري الميديا والتحقق من صلاحية `MEDIA` أو `ALL`.
  * `GET /api/auth/stats`: إحصائيات لوحة التحكم الخاصة بقسم الميديا.
  * `GET /api/records`: جلب سجلات الحملات الإعلانية مع فلاتر التاريخ المتقدمة (اليوم والشهر والسنة).
  * `POST /api/records`: إنشاء سجل حملة مع حساب التكلفة ومستحقات القناة ومستحقات العميل.
  * `PUT /api/records/:id`: تعديل تفاصيل الحملة وحساب فروق الأرباح تلقائياً.
  * `DELETE /api/records/:id`: حذف سجل إعلاني مع تأمين الصلاحيات.
  * `GET /api/channels`: دليل القنوات الإعلانية المعتمدة.
  * `GET /api/suppliers`: دليل الموردين ومسؤولي التوريد.
  * `GET /api/clients`: عملاء قسم الميديا وسجلاتهم.
  * `GET /api/contents` & `/api/content-types`: تصنيف وإدارة المواد الإعلانية وأنواع المحتوى.
  * `GET /api/accounting/sync`: مزامنة الحملات المكتملة مع نظام الفواتير لإنشاء مطالبات مالية.

### 3) خادم الإدارة المركزية (`admin/backend/` - المنفذ `5003`)
* **بيئة التشغيل**: Node.js مع Express.js و TypeScript.
* **إدارة البيانات**: اتصال مباشر عالي الكفاءة عبر مكتبة `pg` (PostgreSQL Pool).
* **أبرز المسارات والـ Endpoints**:
  * `POST /api/auth/login`: تسجيل دخول الإدارة العامة والتأكد من صلاحية `ADMIN` أو `ALL`.
  * `GET /api/auth/me`: التحقق من جلسة الأدمن الحالية.
  * `GET /api/users`: عرض قائمة المستخدمين مع صلاحياتهم (`ALL`، `MEDIA`، `INVOICE`).
  * `POST /api/users`: إضافة مستخدم جديد وتشفير كلمة المرور بـ 10 جولات salt.
  * `PUT /api/users/:id`: تعديل بيانات المستخدم واختصاصه الوظيفي.
  * `PATCH /api/users/:id/status`: تفعيل أو إلغاء تفعيل حساب الموظف بنقرة واحدة (`isActive`).
  * `PUT /api/users/:id/password`: إعادة تعيين وتغيير كلمة مرور أي موظف فوراً.
  * `DELETE /api/users/:id`: حذف مستخدم مع حظر الحذف الذاتي لحساب الأدمن النشط.
  * `GET /api/stats`: إحصائيات فورية للمنظومة بالكامل وحجم المستخدمين النشطين.

## 4. قاعدة البيانات المركزية وجداولها

تستخدم المنظومة قاعدة بيانات **PostgreSQL** موحدة باسم **`oms_invoice_db`**:
* **محلياً**: تعمل عبر خدمة ويندوز `postgresql-x64-18` على المنفذ الافتراضي `5432`.
* **سحابياً (إنتاجي)**: مستضافة على Supabase Cloud.

### 📋 أهم الجداول المركزية والعلاقات:
1. **`users`**: الحسابات المركزية (المعرف، الاسم، اسم المستخدم، البريد، كلمة المرور المشفرة، الدور `role`، نطاق الوصول `systemAccess`، وحالة التفعيل `isActive`).
2. **`clients` & `media_clients`**: بيانات العملاء والشركات والسجلات الضريبية.
3. **`invoices`**: الفواتير، المبالغ الإجمالية، الخصومات، الضرائب، المبالغ المدفوعة، والمتبقية.
4. **`invoice_items`**: البنود والخدمات والكميات وأسعار الوحدات داخل كل فاتورة.
5. **`invoice_taxes`**: تفاصيل الضرائب المطبقة (ضريبة القيمة المضافة 14% وضريبة الخصم والتحصيل 1%).
6. **`approval_rules` & `approval_steps`**: قواعد دورة الاعتماد المالي ومسار موافقة المدير المالي.
7. **`payments`**: سجلات سداد الفواتير وطريقة الدفع والرقم المرجعي وتاريخ السداد.
8. **`media_records`**: سجلات الحملات الإعلانية ومواعيدها وتكاليفها وصافي أرباحها.
9. **`media_channels` & `media_suppliers`**: القنوات التلفزيونية والمنصات الرقمية وموردي الإعلانات.
10. **`audit_logs`**: السجلات الرقابية التي ترصد العمليات وتاريخها وهوية منفذها.

## 5. واجهات المستخدم ونظام التصميم

تم بناء كافة الواجهات بـ **React (18 / 19)** مع **Vite** و **Tailwind CSS**:

* **الهوية البصرية الموحدة (Design System)**:
  * **اللون الأساسي**: الأحمر `#DC2626`، مع لمسات التفاعل `#B91C1C`.
  * **الخلفيات والأشرطة**: الأسود الفاخر `#171717` و `#0B0F17` والرمادي الداكن `#262626`.
  * **خلفية المحتوى**: الرمادي الفاتح المريح للعين `#F8FAFC`.
  * **الخطوط**: خطوط عربية حديثة واضحة مع دعم كامل للاتجاه من اليمين لليسار (`dir="rtl"`).
  * **الأيقونات**: مكتبة **Lucide React** التفاعلية.

### تفاصيل البوابات:
* **بوابة الفواتير (`Invoice/client/`)**: لوحة قيادة مالية، شاشة إنشاء فواتير سريعة مع حساب الضرائب آلياً، معاينة وتصدير PDF، متابعة الاعتمادات، وسجلات العملاء والمدفوعات، ودعم التبديل بين العربية والإنجليزية.
* **بوابة الميديا (`media/frontend/`)**: لوحة تحكم ذكية للحملات الإعلانية، بطاقات إحصائية للأرباح والهوامش، فلترة دقيقة باليوم والشهر والسنة، تصدير واستيراد ملفات Excel و CSV، وإدارة شاملة للموردين والقنوات.
* **بوابة الإدارة (`admin/frontend/`)**: لوحة تحكم مركزية لحسابات الموظفين، نوافذ منبثقة (Modals) للإضافة والتعديل وتغيير كلمات المرور، ومؤشرات وصول واضحة.

## 7. دليل التشغيل السريع والأوامر

### 🚀 أ) التشغيل المباشر بنقرة واحدة (مستحسن للديسكتوب):

1. **تشغيل تطبيق الديسكتوب المحمول (Portable EXE)**:
   اضغط مرتين على:
   👉 **`E:\OMSsystem\OMS Business Suite.exe`**  
   *(يقوم البرنامج تلقائياً بتشغيل الباك إند وقواعد البيانات في الخلفية ويفتح واجهة الديسكتوب مباشرة)*.

2. **تشغيل كافة خوادم الباك إند يدوياً في نوافذ مستقلة**:
   اضغط مرتين على:
   👉 **`start-backend.bat`** (يشغل خوادم 5001، 5002، 5003 وخدمة PostgreSQL).

3. **تشغيل منظومة الويب كاملة مع المتصفح**:
   اضغط مرتين على:
   👉 **`start-all.bat`**

4. **تشغيل أقسام محددة كـ Desktop**:
   * الفواتير فقط: `start-desktop-invoice.bat`
   * الميديا فقط: `start-desktop-media.bat`
   * الإدارة فقط: `start-desktop-admin.bat`

5. **إعادة بناء ملفات الـ EXE بعد أي تعديل كود**:
   اضغط مرتين على:
   👉 **`build-desktop-exe.bat`**

---

### 💻 ب) التشغيل عبر موجه الأوامر (Terminal Commands):

```cmd
# 1. تشغيل خوادم الباك إند:

# 2. تشغيل واجهات الويب (اختياري في حال عدم استخدام EXE):
cd E:\OMSsystem\Invoice\client && npm run dev    # المنفذ 5173
cd E:\OMSsystem\media\frontend && npm run dev    # المنفذ 5174
cd E:\OMSsystem\admin\frontend && npm run dev    # المنفذ 5175

# 3. تشغيل تطبيق الديسكتوب في وضع التطوير:
cd E:\OMSsystem\desktop && npm start
```

## 8. سجل الأخطاء المحلولة والتحسينات المنجزة

| # | المشكلة / الخطأ السابق | السبب الجذري | الحل البرمجي المعتمد |
| :--- | :--- | :--- | :--- |
| **1** | **`ERR_CONNECTION_REFUSED`** | وسوم `<iframe>` كانت تحاول الاتصال بالمنافذ قبل اكتمال إقلاع الواجهات. | بناء خادم SPA مدمج في Electron يخدم ملفات `dist` تلقائياً مع تفعيل التحميل عند الطلب. |
| **2** | **`Cannot find module '@supabase/supabase-js'`** | نقص ملفات الحزمة في `node_modules` لخادم الفواتير. | تثبيت الحزمة وتطوير `prismaClient.ts` ليعتمد على `PrismaClient` المباشر لـ PostgreSQL. |
| **3** | **`هذا الحساب غير مفعّل`** | كتابة `const user = rows;` في كود الأدمن بدلاً من `rows[0]`، مما جعل قيمة `user.isActive` تعود بـ `undefined`. | استخراج أول عنصر `rows[0]` وتصحيح كافة الاستعلامات وتأكيد تفعيل الحسابات 100%. |
